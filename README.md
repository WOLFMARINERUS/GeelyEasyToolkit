# Geely Easy Toolkit

## О проекте

Geely Easy Toolkit — бесплатная Windows-программа для управления мультимедийными системами автомобилей Geely.

Основные цели проекта:

- Простая установка приложений
- Полная работа без интернета
- Поддержка различных моделей Geely
- Работа через разные способы подключения
- Система профилей автомобилей
- Модульная архитектура

---

## Поддерживаемые модели

- Geely Cityray
- Geely Atlas
- Geely Preface
- Geely Monjaro
